
# ALGO-MARATHON

A small collection of finance and algorithmic trading experiments, utilities, and learning projects. The repository contains scripts for data download, basic strategy prototypes, risk analysis, and supporting utilities.

Quick overview
- `fin.py` — OHLCV downloader / data pipeline utilities
- `strategyV1.py`, `portfolio.py`, `portfolio_returns.py` — early strategy and portfolio experiments
- `Diversifiable & non diversifiable risks.py` — risk decomposition example
- `single variant regression.py`, `efficient frontiers.py` — analysis / regression examples

Getting started
1. Create a Python 3.8+ virtual environment
2. Install dependencies (example):

```powershell
python -m pip install -r requirements.txt
```

3. Run a script from the repository root, e.g.:

```powershell
python "Diversifiable & non diversifiable risks.py"
```

Notes
- Many scripts are exploratory. Check each script for required data files (e.g. Excel/CSV inputs) before running.
